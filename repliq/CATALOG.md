Керування в особистому чаті доступне кнопками: «Товари», «Оголошення», «Додати», «Змінити», «Вимкнути», «Оновити каталог». Команди нижче збережено для сумісності.

# Товари Ledgerly та приватне керування Repliq

**Ledgerly** створює товари, розміри, кольори, надходження, резерви й списання.
**Repliq** лише читає їх та веде власні прив'язки оголошень OLX. Telegram-боти,
код і технічні сховища цих проєктів залишаються окремими.

## Початкове налаштування

Підключення SQL задається в `private/responder-settings.json`, Telegram — у
`private/telegram.json`, як описано у README та TELEGRAM.md.

**Один раз виконай оновлений `sql/repliq_reader.sql` під адміністратором
PostgreSQL**, навіть якщо роль читання була створена раніше. Додано тільки
читання полів назви/ID/категорії/бренду/активності товарів і їхніх псевдонімів.
Repliq не отримує прав змінювати Ledgerly або читати замовлення й собівартість.

Приватне керування доступне одному числовому Telegram ID. Якщо `owner_ids`
містить тільки тебе, він використовується автоматично. Якщо в групі кілька
дозволених операторів, додай `admin_owner_id` зі своїм ID у `private/telegram.json`.
Тоді листуватися в групі можуть дозволені оператори, а налаштовувати Repliq —
лише ти. Username для перевірки особи не використовується.

## Щоденна робота

Напиши **особисто Telegram-боту Repliq** `/start`. З'являться кнопки:
«Товари», «Оголошення», «Додати оголошення», «Оновити з Ledgerly».

| Команда в особистому чаті | Дія |
|---|---|
| `/products` | Показати товари з Ledgerly |
| `/products Suvene` | Знайти товар за назвою |
| `/ads` | Переглянути дозволені та вимкнені оголошення Repliq |
| `/ads 123` | Знайти оголошення за частиною ID |
| `/add_ad 123456789` | Прочитати назву свого оголошення й визначити товар |
| `/add_ad 123456789 Broken Planet` | Допомогти зіставленню назвою товару |
| `/edit_ad 123456789` | Вибрати інший товар для оголошення |
| `/edit_ad 123456789 Футболка Gallery Dept` | Явно змінити відповідність |
| `/remove_ad 123456789` | Вимкнути обробку цього оголошення у Repliq |
| `/refresh` | Негайно перечитати каталог Ledgerly |
| `/cancel` | Скасувати введення ID у приватному чаті |

Числа — приклади. Після кнопки «Додати оголошення» можна просто надіслати ID
наступним повідомленням. Для повторного увімкнення використай `/add_ad`.
Команди керування в групі, від інших людей, у пересланих повідомленнях або
від іншого бота ігноруються. Приватні команди ніколи не пересилаються покупцю.

## Як визначається товар

Repliq оновлює активні товари та їхні назви/псевдоніми із SQL кожні 60 секунд.
Додавання товару в Ledgerly не потребує нового блоку в `shop.json` або
копіювання SQL ID. Перейменування зберігає прив'язку за постійним `product_id`.
Видалений або неактивний товар автоматично виключається з обробки після
синхронізації. Точні залишки, як і раніше, перевіряються окремим свіжим запитом.

Оголошення вмикаються **тільки після твоєї команди або явної прив'язки в
налаштуваннях**. Новий товар Ledgerly не відкриває доступ до всіх чатів OLX.

Під час `/add_ad` перевіряється, що оголошення належить підключеному акаунту.
Впевнена й однозначна відповідність назви зв'язується автоматично. Інакше бот
пропонує кнопки з назвами SQL-товарів. Кнопки прив'язані до незмінного SQL ID,
твого акаунта, поточного OLX-акаунта та мають строк дії 10 хвилин.

Збережені відповідності й підтверджені назви допомагають зіставляти наступні
оголошення. Це локальна пам'ять Repliq, без платного ШІ та навчання на даних
Ledgerly. Однакові назви різних товарів не вважаються однозначним збігом.

Перед увімкненням або зміною оголошення фіксуються його поточні лічильники
діалогів: старі повідомлення не стають приводом для автоматичної відповіді.
Зміна прив'язки скасовує старі чернетки цього оголошення. Нові налаштування
з Telegram застосовуються без перезапуску.

## Що залишається у shop.json

`shop.json` тепер містить загальні правила магазину та необов'язкові профілі
товарів: перевірені заміри/сітки, характеристики й ціни. Старі явні прив'язки
підтримуються; налаштування з Telegram мають пріоритет, включно з вимкненням.

Для нового товару без власної сітки Repliq не копіює розміри Suvene або
Gallery Dept. Він може перевіряти наявність конкретного розміру з SQL, але
підбір за зростом/вагою передасть на уточнення. Ціну можна отримати з власного
оголошення, якщо OLX повернув однозначну суму у гривнях; профільна ціна має
пріоритет. При різних цінах того самого товару в оголошеннях без профільної
ціни потрібне особисте уточнення.

Локальні прив'язки, каталог-кеш і черга керування зберігаються у власному
`private/conversations.sqlite3` Repliq. Це не бізнес-база Ledgerly.
Без змін у каталозі кеш не переписується повністю щохвилини. На PostgreSQL
є одна сесія читання, а додаткові каталожні запити виконуються раз на хвилину
та за твоєю командою. За недоступної SQL використовується останній кеш для
назв; наявність без перевірки не підтверджується, нові прив'язки не активуються.

Перевірки додані в `tests/test_catalog_registry.py` і `tests/test_telegram_bridge.py`.
Результати перевірок на Python 3.9.6 та 3.13.18 наведено в TESTING.md.
Реальні інтеграції перевіряються окремо: [TESTING.md](TESTING.md).
