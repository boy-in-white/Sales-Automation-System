Відкрити портал OLX ↗
OLX вимагає загальнодоступну адресу й перевіряє заявку. Заповнення URI саме по собі ще не надає доступ до API.

2Надай дозвіл Repliq

Після схвалення заявки OLX надасть Client ID та Client Secret. Внеси їх тут і збережи.
